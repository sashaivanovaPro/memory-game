# Memory Game

Игра на поиск карт, на vanilla JavaScript: игрок открывает карточки и запоминает их расположение, чтобы найти все совпадения за наименьшее число ходов.

RS School task: [Memory Game](https://github.com/rolling-scopes-school/tasks/blob/master/tasks/memory-game/README.md).
The app is developed in the `memory-game` branch.
